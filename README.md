# Cloud Resume Backend

Serverless API for visitor counter.

## Tech Stack
- AWS Lambda (Python/Node.js)
- API Gateway
- DynamoDB

## API Endpoints
- GET /visitor-count
- POST /visitor-count

## Deployment
Automated via GitHub Actions

See main project: [sileye-cloud-resume](https://github.com/Sileye00/sileye-cloud-resume)
